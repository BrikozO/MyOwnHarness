# StepCards

Четыре карточки-шага проекта с обводкой `card-border`, номером-бейджем и подписью практики.

**Что передать:** 3–4 шага `{номер, название, что делаем, подпись «Практика N · тема»}`.

- `.mt-step`: бейдж `.mt-badge` 72px (`badge-bg`, цифра `badge-number`) → `card-title-lg` → `body` → подпись `caption` цветом `eyebrow`, прижатая к низу.
- Обводка 2px `card-border`, радиус `radius-card`; фон слайда остаётся белым.
- Для плана занятия используйте `AgendaSlide`, а не эти карточки.
