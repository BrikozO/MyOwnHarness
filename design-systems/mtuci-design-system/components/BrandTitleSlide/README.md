# BrandTitleSlide

Титульный слайд по шаблону брендбука: белый фон, линейный рисунок корпуса, полный логотип с дескриптором и гексагоны в углах.

**Что передать:** название курса или мероприятия (1–2 строки), строку с годом или подразделением.

- Используйте для обложки всего курса, выступлений и материалов вне занятий; обложку занятия делайте через `CoverSlide`.
- Слои: `campus-building-line.png` на весь слайд → гексагоны `hex-corner-primary.svg` (`HexCorners`) → `mtuci-logo-full-primary.png` (в PNG есть свои поля 144px — не обрезайте) → текст.
- Заголовок — `cover-title`, цвет `heading`; строка ниже — `cover-kicker`, цвет `eyebrow`.
- Английская версия: логотип `mtuci-logo-en-primary.svg`.
