# CodeBlock

Блок кода или терминала на `code-bg` с подсветкой синтаксиса из токенов.

**Что передать:** код как текст (`<pre class="mt-code code">`), необязательную подпись над блоком (`p.mt-label.card-title`: имя файла, «Терминал», «def»).

- Размер по объёму: `code-lg` до 7 строк на всю ширину, `code` до 13 строк, `code-sm` для итоговых листингов до 18 строк.
- Подсветка — `span` внутри `pre`: `.k` ключевое слово (`code-keyword`), `.s` строка (`code-string`), `.c` комментарий (`code-comment`), `.f` имя функции (`code-function`), `.t` тип (`code-type`), `.p` приглашение `>>>` или `$` (`code-function`). Остальное — `code-text`.
- Результат вызова показывайте комментарием в той же строке: `print(c)    # {'phone': ''}`.
- Радиус `radius-code`, отступ `pad-code` по горизонтали. Не кладите код на белый фон и не делайте скриншоты IDE.
- Подсветку не обязательно расставлять вручную: `<pre class="mt-code code" data-lang="python">` + `MtuciSlides.highlightAll()` из `components/bundle.js` раскрасит код по тем же правилам (имя функции выделяется только после `def`, как в образце).
