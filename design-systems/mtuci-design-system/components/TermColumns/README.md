# TermColumns

Три-четыре колонки «термин — пояснение» под блоком кода или схемой.

**Что передать:** 3–4 пары `{термин, пояснение до трёх строк}`.

- `.mt-terms` (4 колонки) или `.mt-terms--3`; термин `card-title` (`heading`), пояснение `body-sm` (`ink`).
- Порядок колонок повторяет порядок частей кода над ними.
