# AgendaSlide

План занятия: до шести карточек `card-bg` сеткой 3×2, в каждой время, тема и что делаем.

**Что передать:** список пунктов `{время, тема, подпись}` — 3, 4 или 6 штук.

- Сетка `.mt-grid.mt-grid--3`, карточки `.mt-card` (радиус `radius-card`, отступ `pad-card`, высота от 226px).
- Время — `eyebrow`, тема — `card-title-lg` (`heading`), подпись — `body` (`ink`).
- Сумма минут должна совпадать с длительностью пары. Тема — те же слова, что в названиях разделов.
