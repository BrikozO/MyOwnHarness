# Callout

Выноска-вывод на `card-bg`: короткий заголовок и, если нужно, одна-две строки пояснения.

**Что передать:** заголовок-вывод; пояснение (необязательно).

- Радиус `radius-code`, отступ `pad-callout`; заголовок `card-title` (`heading`), текст `body-sm` (`ink`).
- Одна выноска на слайд, в конце колонки с текстом или под блоками кода. Не дублируйте в ней заголовок слайда.
