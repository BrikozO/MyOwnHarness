# ReferenceDiagram

Схема «несколько имён → один объект» для ссылок, изменяемых объектов и значений по умолчанию.

**Что передать:** 2–3 имени с подписью (где живёт имя) и описание объекта.

- Ячейки имён `card-bg`, радиус `radius-box`; имя — моно `card-title` (`heading`), подпись `caption` (`ink`).
- Стрелка «→» цветом `heading`; объект — `brand-primary`, радиус `radius-row`, подпись `on-dark-kicker`, значение моно `on-dark`.
