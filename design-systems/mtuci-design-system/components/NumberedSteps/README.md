# NumberedSteps

Нумерованный список задания с круглыми бейджами; справа обычно ставится ожидаемый вывод в `CodeBlock`.

**Что передать:** 3–4 пункта (функция — что делает) и, по желанию, пример запуска.

- `ol.mt-steps`, в каждом `li` бейдж `.mt-badge.mt-badge--sm` (52px) и текст `list-item` (`ink`).
- Раскладка слайда практики: список слева (≈770px), код справа, промежуток 110px.
- Под списком можно дать одну строку-условие стилем `card-title` цветом `heading`.
