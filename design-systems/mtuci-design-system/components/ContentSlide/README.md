# ContentSlide

Каркас любого белого слайда: надзаголовок, заголовок, необязательный лид, тело и колонтитул.

**Что передать:** надзаголовок (раздел · тема), заголовок в одну строку, лид (необязательно), содержимое тела, текст колонтитула и номер слайда.

- `header.mt-head` (верх `eyebrow-top`): `p.mt-eyebrow.eyebrow` → `h2.mt-title.slide-title` → `p.mt-lead.lead`.
- `.mt-body` начинается на `content-top`; с лидом добавьте `.mt-body--lead` (336px), для крупного блока кода сразу под заголовком — `.mt-body--code` (262px).
- Поля всегда `slide-margin` (120px): контент живёт в x 120–1800 и заканчивается выше колонтитула (верх 1011px).
- `footer.mt-footer.footer`: слева «МТУСИ · Курс · Занятие N», справа номер слайда, цвет `footer`.
- Надзаголовки практики пишутся так: «ПРАКТИКА 1 · 10 МИН · Проект «Контакты», шаг 1»; решения — «РЕШЕНИЕ · ПРАКТИКА 1».
- Раскладки тела: `.mt-split` (две колонки, 64px), `.mt-split--code` (код 974px + текст), `.mt-grid--2/3/4` (промежуток `gap-grid`).
