# NestedScopes

Вложенные рамки для иерархий «снаружи внутрь» — области видимости LEGB, модули, пакеты.

**Что передать:** 2–4 уровня `{название, пример справа}` от внешнего к внутреннему.

- Уровни по порядку: `brand-primary` → `purple-700` → `purple-400` → `card-bg`; радиусы `radius-panel` → `radius-code` → `radius-row` → `radius-box`.
- Название — `card-title`, пример — моно 26px. На `purple-400` текст `purple-950`, на `card-bg` — `heading`.
