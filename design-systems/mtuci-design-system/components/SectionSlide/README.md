# SectionSlide

Слайд-разделитель перед каждым блоком занятия: номер, название и одна строка пояснения на `slide-bg-dark`.

**Что передать:** номер раздела двумя цифрами (01, 02 …), название раздела, одна строка пояснения.

- Номер — стиль `section-number`, цвет `section-number`; название — `cover-title`, `on-dark`; пояснение — `section-lead`, `on-dark-muted`.
- Белый логотип справа снизу: высота 56px, правый край на 1800px, верх на 944px.
- Номер раздела повторяется в надзаголовке следующих слайдов: «01 · def».
- Колонтитул и номер слайда на разделителе не ставятся.
