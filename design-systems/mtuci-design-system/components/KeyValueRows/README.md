# KeyValueRows

Таблица «код → пояснение»: строки `row-bg` высотой 80px, слева код, справа объяснение.

**Что передать:** 4–6 пар `{код, пояснение}`.

- `.mt-rows` → `.mt-row` (радиус `radius-row`, промежуток `gap-stack`); код — `code-inline` цветом `heading`, пояснение — `body` цветом `ink`.
- Сноска под таблицей (например «Callable — из модуля typing») — `body-sm`, `ink`.
