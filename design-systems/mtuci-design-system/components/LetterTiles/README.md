# LetterTiles

Список карточек с квадратным буквенным бейджем — разбор кода по категориям (L, E, G, B).

**Что передать:** 3–5 пунктов `{буква, моно-имя, пояснение}`.

- `.mt-tile` (`card-bg`, радиус `radius-code`, высота от 120px) → `.mt-badge--square` 64px → моно `card-title` (`heading`) и `body-sm` (`ink`).
- Ставится справа от `CodeBlock`, буквы совпадают с подписями схемы.
