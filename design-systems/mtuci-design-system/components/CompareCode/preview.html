Так нельзя

def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags

add_tag("друзья")  # ['друзья']
add_tag("работа")  # ['друзья', 'работа']

Почему

[] создаётся один раз при def

Так правильно

def add_tag(tag, tags=None):
    if tags is None:
        tags = []
    tags.append(tag)
    return tags

Правило

по умолчанию — только неизменяемое: None, 0, "", ()
