# CompareCode

Два блока кода рядом: «как нельзя» и «как правильно», под каждым короткое объяснение.

**Что передать:** две подписи, два фрагмента кода, под каждым заголовок и строку пояснения.

- Подпись неправильного варианта — `.mt-label--warn` (`warn`), правильного — `heading`. Цвет всегда вместе со словом («Так нельзя», «print — показывает»).
- Колонки `.mt-split` с промежутком 48px; пояснения — `TermColumns`-стили (`card-title` + `body-sm`).
