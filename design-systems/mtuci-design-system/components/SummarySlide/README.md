# SummarySlide

Последний слайд занятия: четыре карточки итогов с ключевым словом кода и крупное «Вопросы?».

**Что передать:** 3–4 пары `{ключевое слово кода, что запомнить}`.

- Карточка `.mt-card` с `.mt-card__code` (JetBrains Mono 36px, `heading`) и текстом `body-sm`.
- «Вопросы?» — `slide-title`, цвет `heading`, слева под карточками.
- Ключевые слова совпадают с разделами занятия (def, lambda, LEGB …).
