# HexCorners

Цепочки гексагонов из мастер-слайда шаблона: справа сверху и слева снизу.

**Что передать:** ничего — это оформление. Выберите вариант по фону.

- На белом — `hex-corner-primary.svg`, на `slide-bg-dark` — `hex-corner-white.svg`.
- Размер 200×216px; правый верхний прижат к углу; левый нижний отражён по горизонтали и повёрнут на 270° (`.mt-hex--bl`), как в мастере pptx.
- Гексагоны — часть шаблона брендбука (`BrandTitleSlide` и слайды по шаблону). В слайдах занятия по образцу их нет; не смешивайте оба оформления в одной презентации.
