# CoverSlide

Первый слайд занятия на `slide-bg-dark`: курс, номер занятия, тема и крупный символ темы справа.

**Что передать:** название курса, номер занятия, тему (1–2 строки), подтему (одна строка), один символ темы — λ для функций, `{}` для словарей, `#` для комментариев и т. п.

- Разметка: `section.mt-slide.mt-slide--dark` → `img.mt-cover__logo` (белый логотип `mtuci-logo-ru-white.svg`, высота 80px, x 120, y 90) → `svg.mt-cover__glyph` с одним `<text x="1324" y="1118">` → `.mt-cover__text`.
- Стили текста: `cover-kicker` (`on-dark-kicker`), `cover-lesson` прописными с разрядкой, `cover-title` (`on-dark`), `cover-subtitle` (`on-dark-muted`).
- Символ — цвет `cover-glyph`, кегль 1000px, нижний край обрезан краем слайда. Это декор: не ставьте туда слово.
- Не добавляйте фото, иллюстрации и гексагоны на эту обложку — у неё один акцент.
