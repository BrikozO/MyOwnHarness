Система для презентаций к занятиям курсов МТУСИ. Слайд 16:9, холст **1920×1080 px**; все размеры ниже заданы для него (1pt шаблона pptx = 2px). Основа — фирменный цвет `brand-primary` (#372579), шрифт Montserrat и тёмные блоки кода `code-bg`.

## Как пишем

- Заголовок слайда — одна строка, утверждение или тема: «Аргументы передаются по ссылке», «lambda как аргумент key». Без точки в конце.
- Лид под заголовком — одна строка, которая объясняет суть: «Параметр получает не копию, а ссылку на тот же объект».
- Подписи и пояснения — со строчной буквы, коротко, без точки: «практика: функции команд», «отдаёт результат и завершает функцию».
- Задания — повелительное наклонение на «вы»: «Объявите псевдонимы Card, Book и Groups», «Запустите mypy и исправьте ошибки».
- Разделитель в надзаголовках и колонтитуле — средняя точка с пробелами: «01 · def · память», «МТУСИ · Python · Занятие 5». Кавычки — «ёлочки», тире — длинное «—», буква «ё» пишется.
- Восклицательных знаков и эмодзи нет. Знаки «×» и «✓» допустимы в начале пункта как маркеры ошибки и правильного варианта.
- Код и имена из кода (`ask()`, `book`, `key=`) пишутся как в Python, без перевода и кавычек.

## Структура занятия

Порядок слайдов из образца «Занятие 5»:

1. `CoverSlide` — курс, номер занятия, тема.
2. `AgendaSlide` — план с минутами.
3. Где остановились и проект занятия — `ContentSlide` с `CodeBlock`, `StepCards`.
4. Для каждого раздела: `SectionSlide` (01, 02 …) → объяснения → «ПРАКТИКА N · M МИН» (`NumberedSteps`) → «РЕШЕНИЕ · ПРАКТИКА N».
5. Сборка проекта (итоговый код), домашнее задание, `SummarySlide` с «Вопросы?».

Обложка курса целиком или выступление вне занятий — `BrandTitleSlide` по шаблону брендбука.

## Цвет

- Фирменный цвет один — `brand-primary`. Фон обложек и разделов (`slide-bg-dark`), заголовки (`heading`), бейджи (`badge-bg`), логотип.
- Белый слайд `slide-bg` — для всего содержания. Текст `ink` (#151515, чёрный брендбука), никогда не чистый #000.
- Второстепенный текст: надзаголовок `eyebrow`, колонтитул `footer`. На тёмном: `on-dark`, `on-dark-muted`, `on-dark-kicker`.
- Плашки: карточки и выноски `card-bg`, строки таблиц `row-bg`, обводка шагов `card-border`.
- Неправильный вариант — `warn`, всегда вместе со словом («Так нельзя»).
- Шкала `purple-950` … `purple-50` — палитра шаблона «для основных элементов»: схемы, вложенные рамки, фигуры.
- `chart-01` … `chart-20` — палитра шаблона «для графиков, диаграмм, фигур». Берите подряд от фиолетовых к жёлтым; в одной диаграмме не больше 6 цветов.
- Используйте только цвета из токенов: шаблон прямо требует «цвета только из цветовой палитры».
- Контраст: все текстовые пары ≥ 4.5:1. Исключение из образца — номер раздела `section-number` на `slide-bg-dark` (2.9:1 при 200px); оставлен как есть.

## Типографика

- Montserrat для всего текста, JetBrains Mono для кода.
- Начертания: Bold, SemiBold, ExtraBold — основные (правило шаблона); Medium — основной текст в образце; Black — только номер раздела как дизайнерский приём. Брендбук сайта называет только Bold для крупных заголовков; шаблон и образец шире, система следует им.
- Шкала (px на холсте 1920×1080):

| Стиль | Размер / интерлиньяж | Где |
| --- | --- | --- |
| `cover-title` | 96 / 102, 800 | тема на обложке, название раздела |
| `cover-subtitle` | 48 / 58, 600 | подтема обложки |
| `slide-title` | 64 / 76, 800 | заголовок слайда |
| `card-title-lg` | 38 / 46, 800 | заголовок карточки плана и шага |
| `lead` | 32 / 42, 500 | лид под заголовком |
| `card-title` | 30 / 38, 700 | заголовок колонки, пункта, выноски |
| `list-item` | 30 / 42, 500 | пункт нумерованного списка |
| `body` | 28 / 38, 500 | текст карточек |
| `body-sm` / `eyebrow` | 26 / 36 и 26 / 32 | пояснения / надзаголовок |

| `code-lg` / `code` / `code-sm` | 36 / 54, 26 / 38, 24 / 36 | блоки кода |

- Кегли шаблона pptx для справки: название презентации 40pt (80px), заголовок 32pt (64px), подзаголовок 24/20pt, текст 14/16/24pt, колонтитулы 12/14pt.
- Меньше 24px на слайде не ставьте.

## Сетка и отступы

- Поля `slide-margin` 120px слева и справа: контент в полосе x 120–1800.
- Надзаголовок с `eyebrow-top` (106px), заголовок сразу под ним; тело с `content-top` (294px, с лидом 336px, крупный код 262px); колонтитул с `footer-top` (1011px).
- Промежутки: между карточками и колонками `gap-grid` 32px, между строками и ячейками `gap-stack` 20px. Отступы внутри: карточка `pad-card` 40px, выноска `pad-callout` 36px, код `pad-code` 44px.
- Радиусы: ячейка схемы `radius-box` 16, строка `radius-row` 20, код и выноска `radius-code` 24, карточка `radius-card` 28, внешняя рамка `radius-panel` 32, бейдж `radius-badge` 50%.
- Теней, градиентов и цветных полосок по краю карточек нет. Плашки отделяются цветом заливки или обводкой `card-border`.
- На слайде не больше двух колонок контента или одной сетки карточек.

## Код

- Код всегда в `CodeBlock` на `code-bg`: никаких скриншотов IDE и кода на белом.
- Подсветка из токенов: `code-keyword`, `code-string`, `code-comment`, `code-function`, `code-type`, остальное `code-text`.
- Вывод программы — комментарием в той же строке (`print(n)    # анна`) или отдельным блоком-терминалом с `>>>`/`$`.
- Код в строках таблиц и карточках на светлом — `code-inline` цветом `heading`.

## Логотип

- На белом — `mtuci-logo-ru-primary.svg`, на `slide-bg-dark` и фото — `mtuci-logo-ru-white.svg`, английская версия — `mtuci-logo-en-primary.svg`, полный с дескриптором — `mtuci-logo-full-primary.png` (только титулы).
- Обложка: белый логотип высотой 80px в левом верхнем углу (x 120, y 90). Раздел: высотой 56px справа снизу. На контентных слайдах логотипа нет — его заменяет колонтитул «МТУСИ · …».
- Логотип не перерисовывают, не перекрашивают и не кладут на пёстрый фон.

## Изображения и оформление

- Шаблон разрешает фирменные иллюстрации (`assets/Illustrations`), иконки (`assets/Icons`), фотографии студентов (`assets/Photos`) и схемы — «когда это необходимо для более полного понимания контента».
- Иллюстрация — одна на слайд, на белом, рядом с текстом. Фото — половина слайда или полный кадр.
- Гексагоны `HexCorners` и рисунок корпуса — оформление шаблона брендбука для `BrandTitleSlide` и слайдов в стиле шаблона; в слайдах занятия их нет.
- Схемы стройте из `ReferenceDiagram`, `NestedScopes`, `LetterTiles` и цветов `purple-*`: прямоугольники с радиусами системы, стрелки цветом `heading`.

## Иконки

- Только иконки из `assets/Icons` (шаблон брендбука), один цвет `brand-primary` на светлом, `*-white.svg` на тёмном. Эмодзи и сторонние наборы не используются.
- Размер 64–120px; в одной строке — одного типа (только линейные или только залитые).

## Компоненты

Компоненты — CSS-классы `mt-*` в `components/bundle.css` плюс стили текста из токенов (`class="mt-title slide-title"`). Каждый слайд — `section.mt-slide` 1920×1080; тёмный — с `.mt-slide--dark`. Подробности и разметка — в README и превью каждого компонента.
