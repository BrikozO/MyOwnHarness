Фотографии студентов из шаблона брендбука, сжатые до 1920px по длинной стороне. Ставьте фото на половину слайда или в полный кадр (`object-fit: cover`), не в мелкие рамки; поверх фото — только белый логотип или заголовок на плашке `slide-bg-dark`. Брендбук разрешает фото студентов в оформлении; для новых фото нужны согласия людей в кадре.
