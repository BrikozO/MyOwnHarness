# lofi-usage

Тонкая полоса над полем ввода Claude Code: насколько заполнен контекст и сколько израсходовано из лимитов на 5 часов и 7 дней.

```
ctx ━━━─────── 34% 68k/200k  ·  5h ━━──────── 22% ↺ 2h14m  ·  7d ━━━━━━━━━─ 91% ↺ 3d3h
```

## Что показывает

- **ctx:** заполнение окна контекста, на широком терминале ещё и в токенах.
- **5h, 7d** (и spend, если он есть): процент лимита и время до его сброса.

Цвет полоски зависит от загрузки: зелёный до 60%, песочный до 85%, розовый выше. Числа обновляются после каждого хода, таймеры сброса раз в минуту. Пока над вводом стоит опрос, полоса уступает ему место.

## Установка

Мод входит в маркетплейс [MyOwnHarness](../../../README.md):

```
/plugin marketplace add BrikozO/MyOwnHarness
/plugin install lofi-usage@my-own-harness
```

После правки файлов достаточно выполнить `/reload-plugins`.
