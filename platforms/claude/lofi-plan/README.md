# lofi-plan

Короткий прогресс-бар под полем ввода Claude Code. Он показывает, на каком этапе Claude строит план и сколько шагов уже сделано.

```
◉ проект ━━━━━━──── этап 3/5 · ↻ 15с                 ⏸ plan mode on (shift+tab to cycle)
◉ работа ━━━━━───── 1/2 · ↻ сейчас · пишу dao
```

## Что показывает

- **Пока план формируется:** этап из пяти (изучение → вопросы → проект → согласование → работа), полоску и время с последнего обновления. Этап определяется по тому, какие инструменты вызывает Claude.
- **После одобрения плана:** сколько шагов из списка задач выполнено и какой шаг идёт сейчас.
- **Когда всё готово:** зелёное «● готово». Через две минуты строка снова принадлежит движку.

Подсказка движка (`? for shortcuts`, режим) остаётся справа от бара. На узком терминале она переносится под него.

## Когда появляется и пропадает

- Появляется при входе в plan mode (shift+tab или инструмент `EnterPlanMode`), а также когда у Claude появляется список шагов.
- Пропадает, если выйти из plan mode, пока план ещё не принят. Следующий промпт вне plan mode сбрасывает недостроенный план.
- Сбрасывается по `/clear`.

## Установка

Мод входит в маркетплейс [MyOwnHarness](../../../README.md):

```
/plugin marketplace add BrikozO/MyOwnHarness
/plugin install lofi-plan@my-own-harness
```

После правки файлов достаточно выполнить `/reload-plugins`.
